# AQIntel
**Know what you breathed, and why.**

Delhi's AQI apps show a number. AQIntel shows *your* air and explains it.

## Planned features
- [ ] Auth + health profiles (asthma, child, elderly, outdoor worker)
- [ ] Live AQI map from CPCB/OpenAQ stations
- [ ] ML: hyperlocal AQI estimate + 24h forecast (vs. naive baseline)
- [ ] Agent: "Why is it bad today?" using wind, weather, fire hotspots
- [ ] Personal exposure diary
- [ ] Email/Telegram alerts
- [ ] Deployed live + used by 30+ real people

## Stack
React · Node/Express · MongoDB · Python (FastAPI, scikit-learn) · LLM function calling

## Disclaimer
Not medical advice. Health guidance follows official AQI categories.
